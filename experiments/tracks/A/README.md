# Track A: theoretical and copula modeling for correlated L=3 noise

This track builds an offline Bayes/MAP lookup decoder for the exact one-round,
data-only process used by the benchmark. It owns only this directory. The
parent harness can import `candidate_a.build_decoder(point)` (with the repo
root on `PYTHONPATH`) without changing `solve.py`.

## Model and covariance audit

For data-qubit coordinates `r_i` extracted from
`SurfaceCodeExperiment(distance=3)`, the benchmark's latent Gaussian model is

```text
C_ij = exp(-||r_i-r_j||_2 / xi),  xi > 0.
```

For `xi <= 0`, the implementation uses independent uniforms rather than a
Gaussian latent field. The actual L=3 coordinates, in data-qubit order, are

```text
(1,1), (3,1), (5,1), (1,3), (3,3), (5,3), (1,5), (3,5), (5,5).
```

Thus nearest-neighbor spacing is 2 and, for example, the off-diagonal latent
correlation at that spacing is `exp(-2/xi)`. `noise.py` evaluates the matrix as
`exp(-distance/xi) + 1e-12 I` before Cholesky; the audit records this jittered
matrix and its eigenvalues. Marginals are generated by thresholding a standard
normal at `t = Phi^-1(1-p)`, i.e. `E_i=1{Z_i>t}`. Write `Phi_2` for the
standard **lower-tail** bivariate normal CDF and `barPhi_2` for the joint upper
tail. Inclusion-exclusion gives the exact binary pair covariance as

```text
P(E_i=E_j=1) = 1 - 2 Phi(t) + Phi_2(t,t;rho)
             = barPhi_2(t,t;rho) = Phi_2(-t,-t;rho).
Cov(E_i,E_j) = Phi_2(t,t;rho) - (1-p)^2
             = Phi_2(-t,-t;rho) - p^2
             = barPhi_2(t,t;rho) - p^2.
```

where `rho=C_ij/sqrt(C_ii C_jj)`. The shorthand
`Phi_2(t,t;rho)-p^2` is correct only if `Phi_2` means the **upper-tail**
probability; it is wrong for the conventional lower-tail CDF. At `rho=0`, the
formula must give zero covariance. `rho` is the latent Gaussian correlation
and is not itself the binary covariance. `covariance_validation.json` evaluates
the relation by one-dimensional Plackett quadrature, validates the Cholesky
factor and compares empirical joint probabilities from seeded samples. The
quadrature result is not replaced by a Gaussian or Pearson-correlation
approximation. For the sampler's diagonal jitter `v=1+1e-12`, the audit uses
`t_eff=t/sqrt(v)`, `p_eff=Phi(-t_eff)`, and `rho=C_ij/v`.

## Candidate construction

There are exactly `2^9=512` physical masks. `enumerate_masks()` sends every
mask through the existing `SurfaceCodeExperiment.sample_from_mask`, not a
hand-written stabilizer map. It records the resulting 8-bit detector pattern
in the existing detector-column order and the first Stim observable. The
mapping is checked against GF(2) linearity. There are 256 possible 8-detector
syndrome IDs, although this one-round data-only process reaches only 16; the
remaining table entries are retained and set by the MAP rule's zero-prior tie
convention. The candidate maps a syndrome to the logical class with larger
posterior mass, summing mask priors over all masks with that syndrome and
logical class.

For `xi=0`, mask probabilities are exact iid products. For `xi>0`, each mask
probability is a 9-dimensional multivariate-normal rectangle probability
computed with SciPy's randomized-lattice QMC `_qmvn` conditional
transformation. It is a numerical approximation, not an exact orthant
probability. The build writes per-mask probability error estimates, requested
and actual integration samples, probability normalization diagnostics, 3-SE
table-margin diagnostics, and coarse/refined table changes to
`tables_qmc.json`. The checked-in `frozen_tables.py` is generated from the
refined run and contains only the compact lookup constants used by the
decoder. It does not read files during decoding.

The integration seed is independent of benchmark seeds. No benchmark shots
are used for fitting, selecting, or correcting tables; this avoids train/test
leakage. A table entry with zero physically reachable prior is defined as 0.

## Exact commands

From the repository root, using the repository environment:

```bash
PYTHONPATH=src:. .venv/bin/python experiments/tracks/A/run_track_a.py \
  build --budget 4096 --refine-budget 32768 --seed 902100

PYTHONPATH=src:. .venv/bin/python experiments/tracks/A/run_track_a.py \
  covariance --shots 500000 --seed 902101

PYTHONPATH=src:. .venv/bin/python experiments/tracks/A/run_track_a.py \
  evaluate --shots 10000 --seed 8675309 --label pilot_10k

PYTHONPATH=src:. .venv/bin/python experiments/tracks/A/run_track_a.py \
  evaluate --shots 100000 --validate --label official_100k_5seeds

PYTHONPATH=src:. .venv/bin/python -m pytest -p no:cacheprovider \
  experiments/tracks/A/test_track_a.py
```

The `evaluate` commands implement the official shared-RNG semantics. The
`pytest` command is the targeted contract and artifact check. The evaluator
uses one `numpy.random.default_rng(seed)` and calls the correlated sampler in
the official `challenge_grid()` order. The runner uses precisely that sequence
once per point and passes the same syndrome batch/truth to candidate, final,
and weighted supplied MWPM. Build and decode are timed per point; table
integration is offline and excluded from the official decoder timer.

## Files

* `candidate_a.py`: importable L=3 table decoder and L=5/7 data-only MWPM
  fallback.
* `run_track_a.py`: enumeration, QMC integration, covariance audit, paired
  pilot/validation runner, uncertainty summaries, provenance and memory/time
  receipts.
* `frozen_tables.py`: generated compact table constants.
* `tables_qmc.json`: integration and convergence diagnostics.
* `covariance_validation.json`: coordinate, latent covariance and binary-pair
  validation.
* `audit_track_a.py` and `results_audit.json`: post-run receipt audit for table
  count, hashes, convergence, timing/memory and per-seed claims.
* `results_*.jsonl` and `results_*.json`: point receipts and aggregate results.
* `analysis.md`: interpretation, comparison and limitations.
* `INCIDENT.md`: explicit ownership-violation handoff concerning pre-existing
  untracked root coordination files.

## Scientific decision rule

The L=3-specific comparison is primary. Full-grid numbers include the
explicit L=5/7 fallback and are reported separately, so a full-grid aggregate
cannot hide or create an L=3 effect. Point estimates are accompanied by
Wilson intervals; paired candidate-vs-final differences use discordant-shot
counts, exact McNemar p-values and an approximate paired interval. The five
official seeds are held out from the 10k pilot and use the repository's
`VALIDATE_SEEDS = [42, 137, 256, 1729, 31415]`.
