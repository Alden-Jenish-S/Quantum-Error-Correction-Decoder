The reorganization keeps the benchmark implementation under `src/`, the final challenge file at root `solve.py`, and research tooling under `scripts/`. The final local environment used Python 3.10.20, NumPy 2.2.6, SciPy 1.15.3, Stim 1.15.0, and PyMatching 2.3.1.

## Reproduction commands

```bash
uv sync --dev
uv run pytest
uv run python run.py --shots 1000000
uv run python run.py --validate --shots 50000
```

The baseline and candidate comparison is reproducible with:

```bash
uv run python scripts/run_experiment.py --decoder baseline --shots 50000 --validate --output experiments/baseline_50k_validate.jsonl
uv run python scripts/run_experiment.py --decoder final --shots 50000 --validate --output experiments/final_50k_validate.jsonl
uv run python scripts/make_plots.py --baseline experiments/baseline_50k_validate.jsonl --improved experiments/final_50k_validate.jsonl --outdir plots
uv run python scripts/verify_submission.py --shots 100000 --output experiments/verification_full_100k.json
uv run python scripts/make_hybrid_plots.py --input experiments/hybrid/official_1m_5seeds_serial.jsonl --outdir plots
```
